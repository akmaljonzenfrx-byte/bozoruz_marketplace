# BozorUz - Zamonaviy Ko'p Sotuvchili Onlayn Savdo Platformasi

O'zbek tilidagi to'liq funksional marketplace platformasi: qidiruv, katalog, muddatli to'lov kalkulyatori, SMS-simulyatsiyali avtorizatsiya, sotuvchi va admin boshqaruv paneli, promokodlar va buyurtma hisob-fakturasi.

## Ishga tushirish

Ilovani 'python app.py' bilan ishga tushiring va http://localhost:5000 manziliga kiring. Baza va 60+ mahsulot dastlabki ishga tushishda avtomatik yaratiladi. Admin kirish: admin / admin123.

`python app.py`

_Jarvis tomonidan yaratildi._
